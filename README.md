# DApp Setup with MetaMask, Ganache, and Truffle

## Prerequisites

- [Node.js](https://nodejs.org/)
- [MetaMask browser extension](https://metamask.io/)
- [Ganache](https://trufflesuite.com/ganache/)
- [Truffle](https://trufflesuite.com/)

---

## Step-by-Step Guide

### 1. Set up MetaMask

1. **Install MetaMask** as a browser extension (e.g., in Chrome or Firefox).
2. **Create a new account** in MetaMask.
3. In the top left of MetaMask: **Add network** → **Custom network**
    - **Name:** Ganache
    - **RPC URL:** `http://127.0.0.1:7545`
    - **Chain ID:** `1337`
    - **Currency Symbol:** `ETH`

---

### 2. Install and start the project

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start Ganache on port 7545:

   ```bash
   ganache --port 7545
   ```

3. **New Terminal:** Compile the smart contracts:

   ```bash
   truffle compile
   ```

4. Deploy the contracts (reset to ensure a clean deployment):

   ```bash
   truffle migrate --reset
   ```

---

### 3. Copy MyContract JSON

Copy the contents of:

```
build/contracts/MyContract.json
```

to:

```
utils/MyContract.json
```

(Create the file if it doesn’t exist.)

---

### 4. Start the app

```bash
npm start
```

The web app will open at: [http://localhost:3000](http://localhost:3000)

---

### 5. Import accounts into MetaMask

The 10 accounts generated by Ganache (`ganache --port 7545`) can be added to MetaMask as follows:

- Menu → **Import account**
- → **Private key** (from Ganache)

Be sure to select the **Ganache network** created in step 1.

---

### 6. Test with multiple users

To log in with a second account:

- Open a new **browser profile** (e.g., in Chrome).
- Install MetaMask in that profile.
- Import a **different private key** from Ganache.
- This ensures separate sessions in separate browser tabs/windows.
